observing terminal state, and handling retries.

## Improvements Applied During The Run

- GitHub discovery now produces a 5,000-repository seed instead of relying on the 30-repository Stage-1 corpus.
- Discovery shards are interleaved by term and language to avoid early language bias.
- Discovery filters out SDK/client-only, template/tutorial, prompt-pack, editor-extension, GitHub Action, CLI-only, and over-large candidates.
- Streaming execution can resume from partial JSONL output and process repositories in parallel.
- Collection uses shallow, single-branch, tagless clones and removes checkouts after extraction.
- Extractors skip unreadable files and directories instead of recording fatal analysis errors.
- Source-route extraction ignores client-style `api.get/post/...` calls, test files, and language-incompatible route regexes.
- Decorator-style routes use the following handler symbol, avoiding leakage from the previous handler.
- Path normalization handles typed brace parameters such as `{repo_id:path}`.
- Candidate reports show capped evidence counts and dominant repository evidence share to expose generated-spec concentration.
- Normalization deduplicates evidence per repository, concept, method, normalized path, and source kind.
- Scoring now includes a strict-mode score that excludes broad heuristics from RFC triage.
- Source-route extraction now includes ASP.NET minimal API, Laravel `Route::`, and Phoenix router routes.
- Cancellation reports now measure whether a cancel route links to the same
  operation resource as async/status/result/progress evidence, separating likely
  operation cancellation from business-domain cancellation.

## Remaining Caveats

- The current seed is metadata-filtered; it still contains some repositories with no detectable HTTP route evidence.
- Large generated OpenAPI/Kubernetes catalogs can dominate raw evidence volume, so RFC decisions should rely on independent-family counts and capped evidence metrics.
- Dynamic route registration remains undercounted for frameworks without dedicated route extraction.
- The `4,993` independent-family count is still very close to repository count;
  route-set similarity and generator fingerprints are needed before making
  strong independence claims.
- Manual sampling must label `operation-cancellation`, `domain-state-transition`,
  and `ambiguous` before these counts are used in an Internet-Draft.
